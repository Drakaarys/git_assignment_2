1 Repositories
GitHub lets you create repositories (repos) to store your code, documentation, and project files in one place.

2 Version Control with Git
GitHub is built around Git, allowing you to track changes, revert to previous versions, and collaborate without overwriting work.

3 Pull Requests (PRs)
Developers can propose changes, review code, discuss improvements, and merge updates into the main branch safely.

4 Branching
You can create separate branches to work on new features or fixes without affecting the main project.

5 Issues & Project Tracking
GitHub provides issue tracking to report bugs, suggest enhancements, and manage tasks using labels, milestones, and project boards.

6 GitHub Actions (CI/CD)
Automate workflows like testing, building, and deploying code directly within your repository.

7 GitHub Pages
Host static websites directly from a repository—great for portfolios, documentation, or project demos.

8 Collaboration & Access Control
Manage team permissions, review contributions, and collaborate publicly or privately with developers worldwide.
